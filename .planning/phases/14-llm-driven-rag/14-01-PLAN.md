<objective>
Move RAG retrieval from a pre-fetch node into LLM-driven inline tool calling inside generation_node.

RAG-01: Patient asking a clinic-specific question → LLM calls `search_knowledge_tool`; tool result appears as ToolMessage in state["messages"].
RAG-02: `rag_retrieval_node` returns `{}` without touching `rag_context`; graph edge preserved.
RAG-03: For non-booking, non-scheduling messages, `tool_choice="required"` forces the LLM to call the tool; it cannot answer clinic questions from training data.
RAG-04: If the tool returns an empty string, the ToolMessage content is "Sin resultados." and the LLM responds without hallucinating clinic data.

Implementation:
1. rag_retrieval_node → returns {} (no-op, keeps graph edge, preserves existing import chain)
2. generation_node general path:
   - Remove rag_context reading and XML injection
   - Add: search_tool = make_search_tool(tenant_id)
   - Add: llm_with_tools = _llm.bind_tools([search_tool], tool_choice="required")
   - First call: llm_with_tools.invoke(messages_for_llm)
   - If tool_calls: execute tool inline → ToolMessage → second _llm.invoke → return response
   - If no tool_calls: return first response directly
3. Tests:
   - test_rag_retrieval.py: all 5 tests rewritten to verify no-op behavior
   - test_generation.py: update _make_mock_llm + all general-path tests + add 3 new RAG tests

Booking, scheduling, shadow mode, and anti-diagnostic paths are NOT touched.
</objective>

def rag_retrieval_node(state: ConversationState) -> ConversationState:
    """Retrieve relevant knowledge chunks for the latest user message.
    ...
    """
    tenant_id = state["tenant_id"]
    messages = state.get("messages") or []
    query = ""
    for msg in reversed(messages):
        if getattr(msg, "type", None) == "human" and getattr(msg, "content", ""):
            query = msg.content
            break
    if not query:
        logger.debug("rag_retrieval.no_query", tenant_id=tenant_id)
        return {"rag_context": ""}
    try:
        search_tool = make_search_tool(tenant_id)
        rag_context: str = search_tool.invoke({"query": query})
        logger.info(...)
    except Exception as exc:
        logger.warning(...)
        rag_context = ""
    return {"rag_context": rag_context}
