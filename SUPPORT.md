# Support

## Questions and usage help

Open a GitHub issue with the `question` label and include:

- What you are trying to achieve.
- Relevant logs or error messages.
- Environment details (OS, Python version, Docker/non-Docker).

## Bug reports

Open a GitHub issue and include:

- Expected behavior.
- Actual behavior.
- Reproduction steps.
- Minimal reproducible payload/config if possible.

## Security issues

Do **not** post security vulnerabilities publicly.
Use the process in [SECURITY.md](SECURITY.md).
